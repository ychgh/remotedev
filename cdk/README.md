# remotedev – CDK project

TypeScript CDK project that provisions the `RemoteDevStack`.

See the top-level [README](../README.md) for full deployment instructions.

## Useful commands

| Command | Description |
|---|---|
| `npm run build` | Compile TypeScript to JS |
| `npm run watch` | Watch for changes and compile |
| `npm run test` | Run Jest unit tests |
| `npx cdk deploy` | Deploy to your default AWS account/region |
| `npx cdk diff` | Compare deployed stack with current state |
| `npx cdk synth` | Emit the synthesised CloudFormation template |
| `npx cdk destroy` | Destroy all resources in the stack |
